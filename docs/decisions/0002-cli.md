# 0002 — Command-line interface: Typer with Rich

## Context

The pipeline is operated by one person from a terminal. It needs discoverable commands, readable
output for status tables, and predictable exit codes so it can later be automated.

## Decision

- **Typer** for commands and options, with sub-apps `db` and `episode`.
- **Rich** for the `status` table.
- Exit code `0` on success, `1` on a handled error, with the message on stderr.
- Stubs that are not implemented yet also exit `1`, so a script never mistakes a placeholder for
  real work.

## Consequences

- `dds --help` is the reference for the command surface; no separate CLI manual.
- Output formatting lives only in the CLI layer. Services return data, not strings.
- Typer keeps the door open to shell completion, if it ever becomes useful.
